# krrood on law-as-code benchmarks

- A benchmark's cases are committed only where its license allows; AGPL-3.0 tests are fetched by a script, never copied in.
- A score compares with the benchmark's own reference answers on its published test split, and says how many cases it covers.
- A gap in krrood is filed on cram2/cognitive_robot_abstract_machine and worked around here, never patched into a copy of krrood.
